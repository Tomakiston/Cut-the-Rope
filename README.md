Recreação do jogo Cut the Rope para fins educacionais, aplicando conceitos de jogos estilo puzzle com física.

---
## 📚 Aprendizados
- Motores de Física
- Fundamentos JavaScript
- Estilo de jogo puzzle com física

## ⚙️ Funcionalidades
- 3 fases diferentes
- Cortar as cordas com o clicar e arrastar do mouse
- Coletar estrelas com o doce
- Dar o doce para OmNom comer
- Estourar bolhas com o clique
- Ativar sopradores com o clique

## 🛠️ Stack
- JavaScript
- HTML5
- CSS3
- Matter
- p5

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/Tomakiston/Cut-the-Rope
```

2. Abra o arquivo `index.html` em seu navegador.
